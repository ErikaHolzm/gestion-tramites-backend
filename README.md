# Gestión de Trámites — Backend

API REST para gestionar trámites personales con fechas de vencimiento. Los usuarios pueden registrar trámites (libreta, patente, permiso, certificado, etc.) y el sistema calcula automáticamente su estado: vigente, próximo a vencer o vencido.

**Stack:** NestJS + TypeScript + MongoDB (Mongoose) + JWT
